  <h1><b>Кинопоиск для Linux</b></h1>

Этот проект использует Electron, чтобы запустить Tizen-версию приложения Кинопоиска на ПК под управлением Linux (если необходимо, запустить этот проект можно на любом устройстве, поддерживающем Electron).

[README.md для v0.1.1](https://github.com/itsflameee/kinopoisk-tv/blob/main/README_old.md)

## Что доступно?
Полностью функционирует:
- Вся библиотека Кинопоиска (фильмы, сериалы, трейлеры и т. д.),
- Яндекс Музыка (включая Клипы, Мою Волну и управление с телефона),
- Подмена типа устройства на Samsung Neo QLED QN90C (QE65QN90CAU),
- Все ТВ-каналы,
- Управление с клавиатуры (полностью), мыши (не полноценное, рекомендуется использование вместе с клавиатурой), геймпада (почти полностью) и пульта (при правильной настройке),
- Яндекс Книги
- Переключение между аккаунтами и Детский Режим,
- "Магазин".

Доступно частично:
- Изменение соотношения сторон и разрешения экрана (экран Steam Deck имеет несоответствие интерфейса к соотношению сторон в некоторых элементах интерфейса, желательно иметь экран 1080p 16:9 или 720p 16:9),
- Использование приложения с VPN или из другой страны (как правило, блокируется либо доступ в приложение целиком, либо отваливаются некоторые элементы интерфейса, особенно "Магазин"), однако вы всё ещё можете попробовать продолжить использование.

Не проверено:
- Покупка опций Яндекс Плюс (рекомендуется оформлять опции и подписки в официальном клиенте на другом устройстве),
- Поддержка на других ОС (при должной настройке возможна поддержка Windows и macOS, в будущем планируется официальный билд под эти платформы).

Недоступно:
- Поддержка на мобильных платформах (iOS и Android), на них нет Electron, а порт Кинопоиска с TizenOS на эти платформы - совершенно другой проект, требующий учесть особенности каждой платформы, и использовать другие инструменты. Использование postmarketOS - единственный официальный способ запустить данный порт на мобильном устройстве, однако вам необходимо использовать ARM-версии бинарника Electron.

## Установка
### AppImage (рекомендуется для Steam Deck на SteamOS)
Установите последний .AppImage из [релизов](https://github.com/itsflameee/kinopoisk-tv/releases).

### AUR (рекомендуется для Arch-based систем, особенно для Steam Deck и других портативных устройств на CachyOS Handheld Edition)
Установите пакет `kinopoisk-tv`, для установки Кинопоиска, использующего установленный глобально Electron (в будущем планируется AppImage-версия пакета):

Для yay:
```bash
yay -S kinopoisk-tv
```

Для paru:
```bash
paru -S kinopoisk-tv
```

### Прямая установка
Начиная с v0.1.1 используется не стандартный Electron, а electron44-castlab. Для использования последней версии необходимо:
1. Установить electron44-castlab:
   
   AUR (Arch Linux, Arch-based) - установите пакет electron44-castlab-bin,
   
   Самостоятельная установка - используйте [репозиторий electron castlabs](https://github.com/castlabs/electron-releases/releases/tag/v44.5.1%2Bwvcus)
   
2. Скопируйте репозиторий в удобную вам папку.
3. Запускайте Кинопоиск TV:
```bash
electron44-castlab .
```
(если electron44-castlab не установлен в /usr/bin или не добавлен в $PATH - используйте прямой путь, например "~/example/electron44-castlab .")

## Инструкция по хоткеям
### Клавиатура:
Стрелки - навигация по интерфейсу,

Enter - замена кнопки "OK" на пульте,

Escape - "Назад"

"\[" и "\]" - перемотка в плеере,

"P" - Пауза/Продолжить.

### Мышь:
Используется обычная навигация мышью, кнопки перемотки, паузы и "Назад" недоступны при использовании только мышью.

### Геймпад:
<img src="https://github.com/itsflameee/itsflameee/blob/main/gamepad_icons/PlayStation_button_X.svg_webp.png?raw=true" width="20" height="20"/> - "OK",

<img src="https://github.com/itsflameee/itsflameee/blob/main/gamepad_icons/PlayStation_button_C.svg_webp.png?raw=true" width="20" height="20"/> - "Назад",

<img src="https://github.com/itsflameee/itsflameee/blob/main/gamepad_icons/PlayStation_Directional_button.svg_webp.png?raw=true" width="20" height="20"/> - навигация,

<img src="https://github.com/itsflameee/itsflameee/blob/main/gamepad_icons/PlayStation_4_button_L1.svg_webp.png?raw=true" width="20" height="20"/> / <img src="https://github.com/itsflameee/itsflameee/blob/main/gamepad_icons/PlayStation_4_button_R1.svg_webp.png?raw=true" width="20" height="20"/> - перемотка назад/вперёд,

### Пульт:
Нативно пульт не будет поддерживаться ни в Linux, ни в Кинопоиске (как правило работает только крестовина и кнопка питания, зависит от модели). Для того, чтобы Кинопоиск можно было использовать с вашим пультом рекомендуется настроить ваш пульт через Input Remapper. Для этого:
1. Подключите пульт к вашему устройству (процесс будет отличаться в зависимости от модели пульта и типа подключения, обычно пульт подключается либо по Bluetooth при зажатии двух кнопок, либо через USB-донгл)
2. Установите Input Remapper
3. Найдите пульт в списке устройств, после чего переназначьте все кнопки так, чтобы они соответствовали хоткеям из раздела "Клавиатура"
