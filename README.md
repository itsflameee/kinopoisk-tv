Этот проект использует Electron, чтобы запустить Tizen-версию приложения Кинопоиска на ПК под управлением Linux (если необходимо, запустить этот проект можно на любом устройстве, поддерживающем Electron).

> [!WARNING]
> **Проект не поддерживает DRM-защиту и протокол проигрывания видео Tizen!**
> 
> Это значит, что для просмотра доступны только некоторые ТВ-каналы, а также трейлеры.
> Раздел Яндекс Музыки работает полностью (включая клипы).

## Что доступно?
Полностью доступен весь UI и механизм авторизации. Частично доступны каналы (например, у меня заработали 2x2, Bridge и ещё некоторые каналы, в общем должны работать все каналы без DRM-защиты).
Также можно полноценно пользоваться Яндекс Музыкой, включая управление с телефона и просмотр клипов, а также плейлисты, "Мою Волну" и подборки.
Поддерживается ввод с курсора, клавиатуры (стрелочки, Enter, ESC) и геймпада (на Steam Deck рекомендуется настроить через Steam Input удобную вам раскладку, например, назначить тачпады на курсор, а гироскоп на курсор при касании стика).

## Установка
### AppImage (рекомендуется для Steam Deck на SteamOS)
Установите последний .AppImage из [релизов](https://github.com/itsflameee/kinopoisk-tv/releases).

### AUR (рекомендуется для Arch-based систем, особенно для Steam Deck и других портативных устройств на CachyOS Handheld Edition)
Установите пакет `kinopoisk-tv`, для установки Кинопоиска, использующего установленный глобально Electron (в будущем планируется AppImage-версия пакета):

Для yay:
```bash
yay -S kinopoisk-tv
```

Для paru:
```bash
paru -S kinopoisk-tv
```

### Прямая установка
Установка может происходить как вам угодно, основные файлы проекта лежат в самом репозитории, для запуска необходим только Electron, установленный в системе. Пример запуска после копирования репозитория:

```bash
electron .
```
