Этот проект использует Electron, чтобы запустить Tizen-версию приложения Кинопоиска на ПК под управлением Linux (если необходимо, запустить этот проект можно на любом устройстве, поддерживающем Electron).

[Старый README.md](https://github.com/itsflameee/kinopoisk-tv/blob/v0.1.0/README.md)

> [!WARNING]
> **Поддержка проигрывателя Tizen не доведена до идеала!**
> 
> В v0.1.1 заработали все каналы, в связи с подменой TizenOS-плеера на HTML5-плеер, который всё это время свободно предоставлялся Кинопоиском. Однако фильмы и сериалы по-прежнему не работают!
> Раздел Яндекс Музыки работает полностью (включая клипы), а раздел каналов с недавних пор показывает всё, что есть в Кинопоиске и поддерживается вашей текущей подпиской.

## Что доступно?
Полностью доступен весь UI и механизм авторизации, а также все каналы.
Также можно полноценно пользоваться Яндекс Музыкой, включая управление с телефона и просмотр клипов, а также плейлисты, "Мою Волну" и подборки.
Поддерживается ввод с курсора, клавиатуры (стрелочки, Enter, ESC) и геймпада (на Steam Deck рекомендуется настроить через Steam Input удобную вам раскладку, например, назначить тачпады на курсор, а гироскоп на курсор при касании стика).

## Установка
### AppImage (рекомендуется для Steam Deck на SteamOS)
Установите последний .AppImage из [релизов](https://github.com/itsflameee/kinopoisk-tv/releases).

### AUR (рекомендуется для Arch-based систем, особенно для Steam Deck и других портативных устройств на CachyOS Handheld Edition)
Установите пакет `kinopoisk-tv`, для установки Кинопоиска, использующего установленный глобально Electron (в будущем планируется AppImage-версия пакета):

Для yay:
```bash
yay -S kinopoisk-tv
```

Для paru:
```bash
paru -S kinopoisk-tv
```

### Прямая установка
Начиная с v0.1.1 используется не стандартный Electron, а electron44-castlab. Для использования последней версии необходимо:
1. Установить electron44-castlab:
   
   AUR (Arch Linux, Arch-based) - установите пакет electron44-castlab-bin,
   
   Самостоятельная установка - используйте [репозиторий electron castlabs](https://github.com/castlabs/electron-releases/releases/tag/v44.5.1%2Bwvcus)
   
2. Скопируйте репозиторий в удобную вам папку.
3. Запускайте Кинопоиск TV:
```bash
electron44-castlab .
```
(если electron44-castlab не установлен в /usr/bin или не добавлен в $PATH - используйте прямой путь, например "~/example/electron44-castlab .")
